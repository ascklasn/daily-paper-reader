## 摘要
数字组织病理学中的全切片图像（WSIs）是在离散倍率级别下获取的，这些倍率编码了从整体组织架构到精细细胞形态的互补诊断信息。然而，深度学习模型对尺度变化仍然敏感。现有的倍率不变方法依赖于在预定义离散分辨率上的多尺度架构，而在临床部署中，采集倍率连续变化，很少与模型的固定训练分辨率对齐，且中间尺度常见，因此鲁棒覆盖需要昂贵的倍率特定模型集成。我们提出条件层归一化（CLN），一种轻量机制，通过小型MLP从输入像素尺寸生成仿射归一化参数，并集成到标准CNN架构中，用于WSI分类和分割。在跨一定像素尺寸范围连续采样的补丁上训练，模型将推理与扫描仪依赖的倍率解耦，并在测试时泛化到任意、之前未见过的尺度。在PANDA前列腺癌数据集上，我们的方法平均匹配或超过独立训练的单倍率模型，并在每个评估倍率（包括训练期间未见过的倍率）中排名前三。这将五模型集成压缩为单一网络，并将训练和推理成本降低约4-5倍，同时保持乘加运算次数不变。代码可在：https://github.com/aflorkowska/OneModelToMagnifyThemAll 获取。

## Abstract
Whole slide images (WSIs) in digital histopathology are acquired at discrete magnification levels encoding complementary diagnostic information from global tissue architecture to fine-grained cellular morphology. Yet, deep learning models remain sensitive to scale variation. Existing magnification-invariant methods rely on multi-scale architectures at predefined discrete resolutions, while in clinical deployment the acquisition magnification varies continuously, rarely aligns with a model's fixed training resolution, and intermediate scales are common, so robust coverage otherwise demands a costly ensemble of magnification-specific models. We propose Conditional Layer Normalization (CLN), a lightweight mechanism that generates affine normalization parameters from input pixel size via a small MLP, integrated into standard CNN architectures for both WSI classification and segmentation. Trained on patches sampled continuously across a range of pixel sizes, the model decouples inference from scanner-dependent magnification and generalizes to arbitrary, previously unseen scales at test time. On the PANDA prostate cancer dataset, our approach on average matches or exceeds independently trained single-magnification models and ranks among the top three performers at every evaluated magnification, including those unseen during training. This collapses a five-model ensemble into a single network and reduces training, and inference cost roughly 4-5 times, while leaving the multiply-accumulate count unchanged. The code is available at: https://github.com/aflorkowska/OneModelToMagnifyThemAll.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：数字组织病理学中，全切片图像（WSIs）以离散倍率获取，不同倍率编码互补的诊断信息（低倍率反映组织架构，高倍率揭示细胞形态）。然而，标准深度学习模型对尺度变化非常敏感，模型在训练固定倍率下表现良好，但一旦评估倍率发生变化，性能显著退化。
- **现有方法的三个根本局限**：
  1. **跨倍率域偏移（Cross-magnification domain shift）**：在某一固定倍率训练的模型，面对未见过的倍率时性能大幅下降，因为不同分辨率下视觉统计特征差异显著。
  2. **计算开销大（Computational overhead）**：为覆盖临床中连续变化的倍率范围，部署时必须组合多个倍率特定模型，训练与推理成本随倍率数量线性倍增。
  3. **离散尺度约束（Discrete scale constraints）**：现有方法（无论是单倍率还是多倍率架构）只能在训练时见过的尺子上运行，无法处理任意中间倍率，而临床扫描仪的采集倍率连续变化，很少恰好落在模型的固定训练分辨率上。
- **核心思路**：不再为每个倍率训练一个模型，而是训练**一个统一模型**，以输入像素尺寸作为条件信号，动态调整内部特征表示的归一化参数，从而在一次前向传播中适应任意倍率。

## 2. 方法论

### 2.1 核心思想
- **条件层归一化（Conditional Layer Normalization, CLN）**：用一个小型多层感知机（MLP）从输入像素尺寸预测层归一化的仿射参数（scale γ 和 shift β），动态调制特征表示。对标准层归一化的改进在于：将固定学习参数替换为与输入像素尺寸相关的动态生成参数。

### 2.2 关键技术细节
- **公式**：
  ```
  x̂ = (x − μ) / √(σ² + ε)
  CLN(x; px) = γ(px) ⊙ x̂ + β(px)
  ```
  其中：
  - x 为输入特征图
  - μ、σ² 为特征图的均值和方差
  - ε = 1×10⁻⁵ 为数值稳定性常数
  - γ(px)、β(px) 由独立的3层MLP（LeakyReLU激活）以像素尺寸 px 为输入动态预测
- **条件信号选择**：使用**像素尺寸**（单位为微米/像素），而非“倍率”（magnification）。像素尺寸是硬件无关的物理量，与具体的扫描仪无关，因此天然具备跨扫描仪泛化能力。
- **架构集成**：CLN 是一个“即插即用”（drop-in replacement）的替换层，可在不修改网络主体结构的情况下集成到任何带归一化层的架构中：
  - **分类**：集成到 ResNet 的每个分辨率阶段
  - **分割**：集成到 U-Net 的编码器和解码器的每个阶段
- **初始化策略**：MLP输出投影层初始化为 γ = 1、β = 0，使 CLN 在初始化时等价于标准层归一化，仅在训练中逐步产生尺度相关性的适应性。
- **条件容量匹配**：每个网络阶段的MLP隐藏维度与该阶段特征维度一致，使条件能力随表示的复杂度自然扩展。

### 2.3 连续倍率训练（Continuous Magnification Training）
- 在每个训练迭代中，补丁的像素尺寸从连续范围内均匀采样（覆盖20×至5×的等价像素尺寸区间），而非像传统方法那样在离散倍率集合上训练。
- 这使模型暴露于密集的分辨率连续体，防止过拟合到扫描仪特定的离散尺度，从而对训练中未见的中间倍率也能泛化。
- **推理时**：模型接受任意像素尺寸输入，不需要事先知道采集倍率，也不需要多尺度输入或模型集成。

## 3. 实验设计

### 3.1 数据集与任务
- **数据集**：PANDA（前列腺癌分级评估挑战赛）数据集，包含具有像素级Gleason分级标注的前列腺活检WSIs。
- **标注处理**：将原始六类标注方案重映射为三类：间质、良性上皮、癌性上皮。分类任务重映射为二分类（良性 vs. 恶性）。
- **数据划分**：按类别组合分层，在slide级别划分（防止数据泄漏）为训练/验证/测试集（约600张slide用于测试，剩余10%用于验证）。
- **数据预处理**：使用组织掩膜排除背景区域；每patch做z归一化；随机水平/垂直翻转和旋转增强；采用加权随机采样缓解类别不平衡。

### 3.2 对比方法与基准设定
- **基线模型**：5个独立训练的单倍率模型，分别训练在 20×、13.3×、10×、6.7×、5× 倍率上。
- **CLN模型**：单个模型，在相同倍率范围（20×至5×）内连续采样训练。
- **评估倍率**：
  - **训练时见过的倍率**：20×、13.3×、10×、6.7×、5×
  - **训练时未见的中间倍率**：16.7×、11.1×、8×、5.7×、4.0×
- **评价指标**：分类用F1分数；分割用Dice分数。逐WSI统计。
- **统计检验**：Wilcoxon符号秩检验，检验CLN模型与单倍率基线之间的差异显著性。

### 3.3 架构与超参数
- ResNet（分类）、U-Net（32初始滤波器，分割）
- AdamW优化器（lr=0.001）、余弦退火（Tmax=200, η_min=1e-5）、早停（patience=100）
- 批量大小128，每epoch采样10,000个patch，resize至224×224

## 6. 主要结论与发现

- **核心结论**：单个CLN条件模型在平均性能上可比或超过5个独立训练的单倍率模型，在**所有**评估倍率（包括训练时未见的中间倍率）中均排名前三。
- **单倍率基线在自身训练倍率附近最强，但远离训练倍率时显著退化**；CLN则在整个倍率范围内保持稳定的性能剖面。
- **效率收益**：将五模型集成压缩为单个网络，训练和推理成本降低约4–5倍，且零额外FLOPs代价（MACs不变）。
- **范式意义**：从“每个倍率一个模型”转向“一个元数据感知的统一模型”，为大规模基础模型开发提供了更轻量的替代路径。

## 7. 优点

- **轻量高效**：机制极简——只需一个小型MLP作为条件分支，即可实现倍率不变性，不改变MACs，训练和推理成本大幅降低（约75–80%）。
- **即插即用**：CLN是标准层归一化的替换层，兼容现有任何带归一化的架构，不需对网络主体做结构性修改，易于落地。
- **物理量条件信号**：使用像素尺寸而非扫描仪定义的倍率，以硬件无关的物理量作为条件，天然具备跨扫描仪、跨机构的泛化优势。
- **连续训练策略**：从离散倍率训练转向连续范围采样，是方法论上的关键创新，使得任意中间倍率可被自然覆盖。
- **设计严谨**：对分类和分割双任务、见过/未见倍率双场景、独立训练的单倍率基线群体进行系统性对比，并用严格的非参数统计检验（Wilcoxon signed-rank test）立体论证了性能差异的显著性。
- **可复现性**：代码开源，数据loader支持固定或连续像素尺寸采样。
- **零成本初始化**：输出投影层初始化为γ=1、β=0，初始状态等价于标准层归一化，不会造成训练不稳定。

## 8. 不足与局限

- **数据集单一**：仅在一个数据集（PANDA，前列腺癌）上验证，Gleason分级相对集中于前列腺组织，结论在其他癌种/组织类型上的普适性未证实。
- **架构覆盖窄**：仅验证CNN类架构（ResNet、U-Net）。作者也承认，扩展到Transformer类模型（如ViT、分层注意力架构）是自然且重要的下一步。
- **缺少关键消融**：没有单独评估CLN模块和连续训练策略各自的独立贡献，也未与已有先进多尺度方法作直接横向比较，削弱了对方法优势来源的归因能力。
- **条件信号单一**：目前仅使用像素尺寸作为条件，而实际病理切片分析中的域偏移还涉及染色协议、扫描仪厂商、组织制备等，这些还都未纳入条件框架（作者将其列为未来工作）。
- **未见倍率的外推边界**：评估的未见倍率大多在训练范围内部或附近（16.7×、11.1×、8×、5.7×），仅4×在训练范围（5×~20×）之外，此时CLN性能已有下降迹象。对于训练范围外的极端倍率外推能力，论文未做更深入的系统性测试。
- **参数增加**：ResNet参数量+13.4%、U-Net+45.1%，虽然MACs不变，但显存占用和存储成本会上升，特别是在对参数敏感的部署场景下需要权衡。
