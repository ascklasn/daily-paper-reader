## 摘要
多模态大语言模型（MLLMs）能够从组织学图像生成病理描述，但千兆像素的全切片图像（WSIs）超出了其视觉上下文限制。标准的平铺处理方法使WSIs变得可处理，却切断了定义肿瘤-间质界面和形态学的组织邻域。我们引入了空间语言消息传递（SLMP），该框架完全在语言空间中进行空间推理，且其构建过程具有人类可读性。SLMP将WSI区域表示为空间文本图：平铺块作为节点，以MLLM描述初始化，边编码空间邻接关系。对于每个平铺块，LLM通过在共享聚合策略下整合来自相邻平铺块的语言消息来细化其描述，该策略在平铺块网格上表现为一个作用于文本而非学习嵌入的自适应局部核。该策略是一个可检查的提示，可通过文本梯度从模型观察到的组织表型中细化，从而在不微调MLLM权重的情况下，实现从局部细胞上下文到更广泛组织形态的自动语义优化。在代表性的HER2和CAMELYON16区域上，SLMP在通用型和病理专用型骨干模型的各种设置中提高了平铺级肿瘤描述准确性，提升幅度为+3.3至+19.6个百分点。随机邻居消融实验证实，这些提升源于空间上下文而非单纯的额外文本，检查优化后的策略可揭示可解释的、组织特异性的决策规则。此外，在无需任何权重更新或微调骨干MLLM的情况下，SLMP显著提升了通用型MLLM的性能，并缩小了其与病理专用模型的差距，为将空间推理纳入基于MLLM的病理分析提供了一种透明且灵活的机制。

## Abstract
Multimodal Large Language Models (MLLMs) can generate pathological descriptions from histological images, but gigapixel Whole Slide Images (WSIs) exceed their visual context limits. The standard tiling workaround makes WSIs tractable yet severs the tissue neighborhoods that define tumor-stroma interfaces and morphology. We introduce Spatial Language Message Passing (SLMP), a framework that performs spatial reasoning entirely in language space, human-readable by construction. SLMP represents a WSI region as a spatial text graph: tiles are nodes initialized with MLLM descriptions, and edges encode spatial adjacency. For each tile, an LLM refines its description by integrating language messages from adjacent tiles under a shared aggregation policy that, on the tile grid, acts as an adaptive local kernel operating on text rather than learned embeddings. This policy is an inspectable prompt that can be refined from model-observed tissue phenotypes via textual gradients, enabling automatic semantic optimization from local cellular context to broader tissue morphology without fine-tuning MLLM weights. On representative HER2 and CAMELYON16 regions, SLMP improves tile-level tumor description accuracy in settings spanning general-purpose and pathology-specialized backbones, with gains of +3.3 to +19.6 percentage points. Random-neighbor ablations confirm that these gains stem from spatial context rather than additional text alone, and inspecting the optimized policies reveals interpretable, tissue-specific decision rules. Besides, without any weight updates or fine-tuning the backbone MLLM, SLMP substantially improves general-purpose MLLMs and narrows its gap to pathology-specialized counterparts, offering a transparent and flexible mechanism for incorporating spatial reasoning into MLLM-based pathology analysis.

## 一、核心问题与研究动机

- **背景痛点**：多模态大语言模型（MLLMs）虽能从组织学图像生成病理描述，但千兆像素级别的全切片图像（WSIs）远超其视觉上下文限制；标准的分块（tiling）策略虽让 WSI 可被处理，却人为切断了**肿瘤-间质界面、淋巴组织结构等关键组织邻域**，丢失了诊断所依赖的空间微环境信息。
- **现有方法缺陷**：主流 WSI 方法（如 MIL、病理基础模型）在数值特征空间中重新引入空间结构，但依赖任务特定训练，可解释性差；智能体式 MLLM 管线虽保留语言推理，却仍逐块独立解读，缺乏直接的跨块空间证据交换。
- **研究核心问题**：如何在不微调 MLLM 权重的前提下，让瓦片级语言描述直接交换局部空间证据，从而恢复 WSI 的空间上下文？

## 二、方法论：SLMP 框架

### 2.1 核心思想
将 WSI 区域构建为**空间文本图（Spatial Text Graph）**：瓦片为节点（存有 MLLM 生成的文本描述），边编码 4 连通空间邻接关系。而后用 LLM 在**纯语言空间**中完成图消息传递，聚合策略是一个**可检查、可优化的自然语言提示词**，行为上等价于在文本上滑动的自适应局部卷积核。

### 2.2 三阶段流程
1. **编码（Encoding）**：将 ROI 划分为 N×N 网格，各瓦片由 MLLM 独立生成初始描述 d⁽⁰⁾ᵢ，不提供任何邻居信息。
2. **空间语言消息传递（Spatial Language Message Passing）**：对每个中心瓦片 v_c，LLM 在提示词 p 控制下整合上下左右四个邻居的描述，更新中心描述：
   - d⁽ᵗ⁺¹⁾_c = LLM_p(d⁽ᵗ⁾_c, d⁽ᵗ⁾_top, d⁽ᵗ⁾_bot, d⁽ᵗ⁾_left, d⁽ᵗ⁾_right)
   - 边界瓦片仅使用 2–3 个可用邻居；同一提示词统一处理边界情形。
   - 该操作在规则瓦片网格上**等价于卷积核滑动**，但表示、消息与聚合规则均为自然语言，可动态解释重复证据、抑制孤立异常、调和冲突信号。
3. **提示优化（Prompt Optimization via Textual Gradients）**：借助 TextGrad 的文本梯度机制，由评估器（frozen GPT-4.1-mini judge）对更新后的描述进行结构化诊断，将错误分类为"策略错误/措辞错误/边缘案例缺失"，并触发针对性修订（改规则、改措辞、补充病理术语）。**所有 MLLM 权重冻结，仅优化提示词 p**。

### 2.3 关键特性
- 优化目标：找到使下游瓦片级判读最优的聚合提示 p*。
- 每次优化迭代都带有可审计的依据：前后端到端的推理过程均为人类可读的自然语言。

## 六、主要结论与发现

1. **SLMP 普遍有效**：在所有 8 个模型-数据集组合中，tile 级肿瘤分类准确率提升 +3.3 至 +19.6 个百分点，C16 上提升最大。
2. **空间上下文是关键**：真实空间邻居显著优于随机邻居；C16 上随机邻居甚至使准确率低于无消息传递基线（0.6250 vs 0.7358），证明增益来自物理邻接关系而非额外文本量。
3. **策略优化必不可少**：未经优化的通用初始提示在 C16 上反而有害（0.6981 < 基线 0.7547），优化后恢复并超越（0.8121）。
4. **可解释的规则涌现**：同一初始提示经优化后，HER2 与 C16 收敛出各自组织特异性的病理决策规则（如 C16 中"2+ 个瓦片出现上皮/腺体结构则覆盖淋巴样解读"的重复证据阈值规则）。
5. **缩小通用-专用差距**：无需任何权重更新，通用 GPT-4.1 在 SLMP 下大幅接近甚至改善病理专用模型水平。

## 七、方法优点

- **全语言空间推理**：中间状态（瓦片描述、消息、策略）全部人类可读，空间推理可审计，而非事后从注意力/显著性图反推。
- **免微调适配**：所有 MLLM 权重冻结，仅优化提示词，计算成本远低于权重微调，且可即插即用于任意 MLLM。
- **策略可读可追踪**：TextGrad 的文本梯度为每次提示修订提供明确的、可追溯的诊断依据。
- **消融设计严密**：随机邻居、初始提示对照双重验证了"空间邻接 + 策略优化"两个核心贡献缺一不可。
- **类比新颖**：将提示词 + LLM 类比为自适应语言卷积核，与数值空间中的 GCN/注意力方法形成鲜明对照。

## 八、不足与局限

- **范围受限**：仅在人工挑选的 ROI 上验证，未扩展到全切片；ROI 已剔除肿瘤仅存在于单瓦片的区域，边界情形被有意回避。
- **单轮消息传递**：每轮增加一次每瓦片生成开销，无法像嵌入池化那样摊销计算成本；多轮的信息传播范围（感受野）仅限于 3×3 邻域。
- **评估代理的偏差风险**：用 GPT-4.1-mini 作判官测量"信息完整性"，可能偏好 GPT 风格描述，对非 GPT 系骨干（如 Patho-R1）存在不公。
- **未与主流方法直接对比**：缺少与数字特征空间中的空间感知模型（如 GCN、TransMIL）在相同协议下的性能对照，难以定位 SLMP 在整体精度谱系中的相对位置。
- **诊断价值的临床验证不足**：实验指标为 tile 级二分类准确率，未涉及生存分析、HER2 状态预测等临床终点；"描述信息更全"与"诊断更准"之间的桥梁仍需更强证据。
- **数据与标注量偏小**：仅 65 个 ROI、来自两个数据集，提示优化所用区域更少（5+7），存在过拟合到特定组织形态的风险。
