## 摘要
理解长达数十分钟的手术视频需要长程时序推理，通过将问题锚定在跨时间分布的视觉证据上，回答在手术阶段的之前、之后或跨阶段发生的事件。现有方法对此处理不佳：单次视觉语言模型（VLM）将整个手术过程压缩以适应其上下文窗口，从而丢失了“之前”或“之后”问题所依赖的细节；而训练模型在何处聚焦的视频智能体则数据需求量大，且对领域外手术的迁移能力差。我们构建了一个将推理与感知分离的智能体框架，并通过进化上下文而非优化权重来改进。一个仅文本的编排器规划需收集的证据，并发出可审计的工具调用序列，而冻结的视觉语言子智能体在像素上执行每次调用，查看、裁剪、检查帧并检索外部知识。我们进一步提出了一种无梯度、奖励门控的启发式技能蒸馏循环，该循环挖掘智能体自身低分轨迹，仅在候选技能提升验证奖励时保留它，从而生成可复用的检索技能，尤其是定向回看。该循环通过扩展外部技能库而非调整权重，仅需约100个标注示例即可适应，远少于监督或强化微调所需。为评估该智能体，我们引入了MedClawBench，这是一个基于自建长时神经外科录像和保留的公开讲座视频测试分区的去泄漏、医生标注的基准，包含1,123个问题。在两个数据集及所有四个评估维度上，我们的智能体始终优于单次VLM和通用视频智能体框架，在长时、领域外的神经外科视频上提升最大。项目页面：https://fyycs.github.io/medclaw/。

## Abstract
Understanding tens-of-minutes surgical videos requires long-horizon temporal reasoning, answering what happens before, after, or across stages of a procedure by grounding the question in visual evidence spread across time. Existing approaches handle this poorly: a one-shot vision-language model (VLM) compresses the whole procedure to fit its context window and loses the detail a "before" or "after" question depends on, while video agents that train the model where to look are data-hungry and transfer poorly to out-of-domain surgery. We build an agent harness that separates reasoning from perception and improves by evolving context rather than optimizing weights. A text-only orchestrator plans which evidence to gather and issues an auditable sequence of tool calls, while frozen vision-language sub-agents execute each call over the pixels, viewing, cropping, inspecting frames, and retrieving external knowledge. We further propose a gradient-free, reward-gated Heuristic Skill Distillation loop that mines the agent's own low-scoring traces and keeps a candidate skill only when it raises a validation reward, yielding reusable retrieval skills, notably directed re-look. Growing an external skill library rather than tuning weights, the loop adapts from only about 100 labeled examples, far fewer than supervised or reinforcement fine-tuning requires. To evaluate this agent, we introduce MedClawBench, a de-leaked, doctor-grounded benchmark of 1,123 questions over self-built long neurosurgery recordings and a held-out public lecture-video test split. Across both datasets and all four evaluation dimensions, our agent consistently outperforms one-shot VLMs and general video-agent frameworks, with the largest gains on the long, out-of-domain neurosurgery videos. Project page: https://fyycs.github.io/medclaw/.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究对象**：长程手术视频推理（long-horizon temporal reasoning），即回答"某步骤之前/之后发生了什么"、"手术跨阶段如何演进"等问题，需要将答案锚定在跨越数十分钟视频的视觉证据中。
- **现有方法的根本缺陷**：
  - **一次性 VLM（one-shot VLM）**：将整段手术视频压缩以适应上下文窗口，导致"之前/之后"类问题所依赖的视觉细节被丢失，且无法回头重新检查关键时刻。
  - **训练型视频智能体（SFT/RL-based agents）**：需要大量任务特定轨迹数据，容易过拟合训练分布，对领域外的长时神经外科手术视频迁移能力很差。
- **核心思想**：不更新任何模型权重，而是**通过演化上下文（evolving context）而非优化权重（optimizing weights）**来提升智能体的检索与推理能力——将"决定看哪里"（规划）与"真正去看"（感知）分离，分别交给冻结模型，并用一个可增长的**外部技能库**来积累检索策略。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架：Agent Harness（智能体框架）

由三部分构成，各司其职，全部模型保持冻结：

1. **文本编排器（Text-only Orchestrator）** $\pi_\theta$（Opus-4.8）：仅通过文本推理，规划需要收集的证据，发出可审计的工具调用序列，直到输出最终答案。它永远不直接看视频。
2. **工具集（Tool Suite）** $\mathcal{T}$：提供从整段视频到单一帧的由粗到细（coarse-to-fine）的五种工具。
3. **冻结视觉子智能体（Frozen Vision Sub-agents）** $\psi$：执行每一个工具调用，在像素层面完成真实感知，返回文本观察。

核心流程遵循 ReAct 范式：第 $t$ 步，编排器基于当前上下文 $c_t$ 输出动作 $a_t = (T_{i_t}, u_t)$，工具返回观察 $o_t = T_{i_t}(V, u_t)$，上下文扩展为 $c_{t+1} = c_t \oplus (a_t, o_t)$，直至输出 STOP 和最终答案。所有状态均保存在上下文中，因此整条轨迹 $\rho = \{(a_1, o_1), \ldots, (a_T, o_T)\}$ 完全可审计。

### 2.2 工具集（由粗到细的五级工具）

| 工具 | 功能 |
|---|---|
| `view_full_video(V, q)` | 两阶段全视频定位：Stage-1 低分辨率读取全片生成时间线并给出候选窗口；Stage-2 对加宽窗口高分辨率重读，输出最紧的相关时间区间 $[s^\star, e^\star]$ |
| `crop_video(V, s, e, q)` | 以裁剪分辨率重新读取指定时间段，返回密集时间线描述 |
| `select_video_frame(V, t, q)` | 对指定时间戳的单帧进行独立描述（跨模型交叉验证） |
| `crop_video_frame(V, t, x1, y1, x2, y2, q)` | 对单帧特定空间区域裁剪并描述，用于小结构/重叠结构精辨 |
| `search_surgical_kb(q, type, k)` | 基于 FAISS 的 RAG 检索工具，从手术知识库中检索 top-k 段落（PubMed 摘要 + 文献归纳的手术技术摘要） |

### 2.3 视觉子智能体

- **视频专家（Video Expert）**：Gemini-3.1-flash-lite / Gemini-3.5-flash，负责 `view_full_video` 和 `crop_video`，处理所有需要跨时间推理的任务。
- **帧验证器（Frame Verifier）**：GPT-5.5，负责 `select_video_frame` 和 `crop_video_frame`，对特定瞬间进行独立的高分辨率检查。
- 该接口设计的优势在于：感知模型可互换，同一编排器可适配更强或更便宜的骨干，便于分离框架与骨干的贡献。

### 2.4 启发式技能蒸馏（Heuristic Skill Distillation, HSD）

这是本文的核心创新，是一个**无梯度、奖励门控**的自我进化循环：

1. **收集失败轨迹（Mining）**：在 60 个问题的挖掘集上，编排器首先盲答（不见金标准），然后对照金标准自我诊断差距，将失败归为三类：
   - **Type A（可操作差距）**：金标准内容在视频中可见，但需要不同的"看法"才能捕捉——这是唯一携带可学教训的类型。
   - **Type B（不可达差距）**：金标准内容在视频中根本不可见（如画外音、外科医生意图、病理结果）。
   - **Type C（已正确）**：无需修改。
2. **提出候选技能（Propose）**：对 Type A 差距，编排器通过原生的技能管理工具将教训写入候选技能库（若已有相同规则的技能则更新而非创建重复项），技能上限为 5 个。
3. **奖励门控保留（Reward-gated Retention）**：每个候选技能单独安装，在 40 个问题的验证集上重新作答重新评分，仅当满足两个条件时才保留：
   - 平均四维奖励提升超过阈值：$R_s > R_0 + \delta$，其中 $\delta = 0.05$（1–5 分制）；
   - 不使任何单个验证问题的得分下降 2 分或以上。
4. **最终产出**：通常收敛为一个核心技能——**定向回看（directed re-look）**：对于"某事件之前/之后发生了什么"的问题，答案不在该事件窗口内部，而在其**相邻窗口**中，因此应裁剪并重读相邻时间窗。

整个过程仅需约 100 个标注示例（60 挖掘 + 40 验证），而对比的 SFT/RL 方法需拟合数百万参数到更大的标注集。

## 6. 主要结论与发现

1. **全面超越**：MedClaw 在神经外科子集上四维平均 2.90，比最强开源模型 VideoChat-R1-7B（2.14）高 +0.76；在 SVU 子集上同样全面领先。
2. **框架增益归因清晰**：相较于各分割对应的一次性视觉骨干，MedClaw 在每个维度提升 +0.17 至 +0.56，证明增益主要来自 agent harness 而非骨干模型。
3. **领域外长视频是最薄弱环节也是最大增益点**：所有开源基线（包括手术专用 SurgVidLM 的 1.94 和 ReWatch-R1-7B 的 1.54）均远低于 MedClaw，说明长时程神经外科视频严重偏离现有模型的训练分布，而 MedClaw 的冻结权重+技能库方案恰恰在此场景表现最好。
4. **定向回看是最大贡献组件**：移除后平均分下降 -0.38，远高于由粗到细定位（-0.16）和 HSD（-0.13）。
5. **框架具有通用性**：将任意骨干（包括较弱的开源模型）包装进框架均获得显著提升（+0.54 至 +1.02），且更换编排器不会导致框架失效（仅降约 0.33 分）。
6. **数据效率**：仅用约 100 个标注示例完成技能蒸馏，远低于 SFT/RL 所需的数十万级数据。

## 7. 优点：方法与实验设计的亮点

- **创新的训练免费范式**：将"学习"从权重空间迁移到上下文/技能库空间，为医疗等标注稀缺领域提供了新路径；完全冻结权重，规避了微调带来的灾难性遗忘和过拟合风险。
- **可审计性**：每个检索步骤都是显式工具调用，形成可检查的轨迹；临床医生可以审查智能体关注了哪里、结论如何推导，这对医疗应用至关重要。
- **数据效率**：约 100 个示例即可完成适应，对比的 SFT/RL 方法需要远超此规模的数据，充分展示该范式在稀缺数据场景的优势。
- **严格的基准构建**：五级过滤级联确保问题无法通过文本先验、旁白或单一帧回答；金标准由医生标注而非模型生成；GPT-5.5 判断器与专家评分的一致性经过验证（κ 0.72/0.86）。
- **归因清晰的消融设计**：通过"同骨干一性次 vs 框架内"的对比，清晰分离了框架增益与骨干模型能力；组件消融和编排器消融相辅相成。
- **工具集设计优良**：由粗到细的五级工具覆盖了从整段视频到单帧局部区域的完整证据收集需求，且有跨模型交叉验证（视频专家 vs 帧验证器）。

## 8. 不足与局限

- **数据规模有限**：神经外科子集仅 14 段视频、259 个问题，来源为单一中心；论文自身在 Limitations 中也承认这一点。基准覆盖的手术类型有限（MVD、肿瘤切除、癫痫灶切除）。
- **依赖商业闭源模型**：编排器（Opus-4.8）、视频专家（Gemini）、帧验证器（GPT-5.5）均为 API 模型，存在不可复现、不可控的风险；论文未报告推理成本，实际应用的经济门槛不明。
- **无算力与性能开销报告**：未说明每问题平均工具调用次数、延迟、token 消耗；缺少与训练方法的成本量化对比。
- **技能库规模与长期适应性未充分探究**：技能数量上限为 5，实际收敛后的技能库非常小；HSD 循环在多轮迭代、更大技能库条件下的表现未验证。
- **基准设计仍可能有残余偏差**：SVU 子集自讲座视频，虽经旁白过滤，但讲座视频的画面风格、节奏与真实手术有差异；神经外科子集的"忠实度过滤"依赖 GPT-5.5 与医生标注的一致性，仍有自动评判残余误差风险。
- **未与同范式方法直接对比**：相关工作提到的 MedScope 等医学视频工具调用智能体未被纳入实验对比（虽然其训练范式不同，但对比仍能更全面地定位 MedClaw 的贡献）。
- **未报告统计显著性**：增益是否会随问题子集变化产生波动，未做置信区间或显著性检验。
