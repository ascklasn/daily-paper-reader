## 摘要
当不同细胞类型在形态上相似时，就会产生细胞模拟。人类病理学家利用周围组织背景来解决这种歧义，而当前的视觉模型要么缺乏上下文推理能力（细胞基础模型），要么无法在细胞层面进行操作（病理学多模态大语言模型，MLLMs）。我们提出了Loki-OT，它通过非平衡最优传输将区域级组织推理传播到单个细胞预测，并利用来自MLLM的密度先验作为模糊细胞重分配的软引导。Loki-OT的动机源于一个观察：预训练的细胞基础模型特征已经编码了包括组织背景在内的判别性信息，但标准的细胞级监督未能有效利用组织背景。所得到的传输计划被蒸馏到一个轻量级的学生MLP分类器中，该分类器在预训练特征空间内学习上下文感知的决策边界。在独立的TCGA-BRCA队列上，Loki-OT相较于完全监督的领域内PanopTILs分类器，实现了更低的患者级MAE，并在上皮丰富的模拟组织中提高了F1分数，该模型使用了基于通用领域细胞基础模型构建的278个弱区域级MLLM估计。代码：https://github.com/xiangli980/Lymphocyte_Mimicry_Correction_via_Loki_OT

## Abstract
Cell mimicry arises when different cell types appear morphologically similar. Human pathologists resolve this ambiguity using surrounding tissue context, whereas current vision models either lack contextual reasoning (cell foundation models) or cannot operate at the cell level (pathology MLLMs). We present Loki-OT, which propagates region-level tissue reasoning to individual cell predictions via Unbalanced Optimal Transport, using MLLM-derived density priors as soft guidance for ambiguous cell reassignment. Loki-OT is motivated by the observation that pretrained cell foundation model features already encode discriminative information, including tissue context, but standard cell-level supervision fails to use tissue context effectively. The resulting transport plan is distilled into a lightweight student MLP classifier that learns context-aware decision boundaries within the pretrained feature space. On the independent TCGA-BRCA cohort, Loki-OT achieved lower patient-level MAE than the fully supervised in-domain PanopTILs classifier and improved F1 in epithelium-rich mimicry tissues, using 278 weak region-level MLLM estimates built on a general-domain cell foundation model. ## 2. 论文提出的方法论

### 2.1 总体框架（Loki-OT）
- 四个核心模块：(a) 细胞特征编码、(b) MLLM知识先验提取、(c) 非平衡最优传输（UOT）仲裁器、(d) 两阶段课程蒸馏。
- 推理时仅运行轻量级MLP学生分类器，无需MLLM查询或OT计算。

### 2.2 细胞表征编码（CellViT++，SAM-H骨干）
- **形态嵌入** \( z_i \in \mathbb{R}^{1280} \)：编码器末层ViT token，捕获核形态。
- **上下文嵌入** \( c_i \)：细胞边界框±5个token（≈80像素）窗口内patch token的均值池化。
- **感知先验** \( a_i \in \Delta^2 \)：基线模型（Lizard）的逐细胞类别概率（压缩为淋巴/非淋巴二分类）。
- 将 \([z_i; c_i]\) 拼接形成上下文增强特征空间，使形态相同但环境不同的细胞可分。

### 2.3 MLLM知识先验
- 使用通用指令跟随MLLM（**Claude Sonnet 4.5**），对每个（ROI，组织亚型）区域查询一次，返回区域级淋巴密度估计 \( b \in \Delta^2 \)。
- 设计专门的提示词协议：系统提示区分“解剖学概念”与“视觉观察”以减少幻觉，输出结构化JSON。
- MLLM仅训练阶段使用；推理不依赖。

### 2.4 非平衡最优传输（UOT）
- **代价矩阵**：\( C_{ik} = \text{Cost}_{\text{percept}}(i,k) + \text{Cost}_{\text{logic}}(i,k) \)。
  - 感知代价：\( 1 - a_{i,k} \)（保留高置信预测）；
  - 逻辑代价：对**上皮丰富组织（T1/T3/T4）** 中的淋巴细胞标签加惩罚 \( \text{ReLU}(s_i)^2 \)，其中 \( s_i = \cos(z_i, c_i) \)——真实淋巴细胞应与其周围上皮在形态上明显不同，细胞与上下文越相似，越不应标记为淋巴细胞。
- **优化目标**（公式2）：
  \[
  \min_{\pi \ge 0} \langle C, \pi\rangle - \epsilon H(\pi) + \tau \cdot KL(\pi\mathbf{1} \| u) + \rho \cdot KL(\pi^\top \mathbf{1} \| b)
  \]
  - \( \epsilon = 0.1 \)（熵正则）、\( \tau = \rho = 3.0 \)（KL散度松弛因子）；
  - UOT允许源/目标边缘分布偏离（相比平衡OT更稳健），缓冲MLLM的不确定性。

### 2.5 两阶段课程训练
- **触发条件**：仅当基线淋巴密度超过MLLM估计 ≥10%（\( \Delta = \bar{a}_{\text{lymph}} - b_{\text{lymph}} \ge 10\% \)）时应用UOT校正；否则基线预测被保留（自蒸馏）。
- **Stage 1（区域比例监督）**：用单侧铰链损失将区域平均预测拉向MLLM密度，仅抑制过预测、容忍小误差；低偏差区域用KL保持基线。
- **Stage 2（UOT教师蒸馏）**：以UOT传输计划 \( \pi_i \) 为软目标（温度T=4），结合硬标签交叉熵锚（教师argmax）防止概率坍塌；校正区域之外的单元回退到Stage-1预测。

## 3. 实验设计

### 3.1 数据集
- **训练集**：TIGER挑战数据，135个ROI（1024×1024像素，约8万核），来自2家医院，共278个（ROI, 组织亚型）区域，7种组织亚型（T1–T7）；训练集以T1（43.5%）为主、T6仅3.3%。
- **测试集**：TCGA-BRCA独立子集，1,741个ROI（中位143×143像素，64K核，共124位患者），与训练集**零医院重叠**；测试集以T6为主（32.8%）——属**组成偏移**而非密度偏移。
- **MLLM先验质量**：与训练GT对比，Pearson r=0.58，MAE=11.7%，偏差+6.6%——粗粒度但有方向性。

### 3.2 对比方法与基线
- **Lizard**：大规模泛域结直肠（结肠）标注训练的MLP，零样本迁移至乳腺癌。
- **PanopTILs**：用80万in-domain TCGA-BRCA核（密集细胞级标注）重训练的MLP。
- **Context-soft**：仅Stage 1训练（区域密度比例正则）——同时作为Stage-1消融与独立对比方法。
- **OT/UOT-Teacher**：平衡/非平衡OT求解器直接输出（仅教师，不可部署）。
- **Loki-OT**：两阶段课程蒸馏的最终可部署模型。

### 3.3 评估指标
- **细胞级**：全局微平均Precision、Recall、F1、AUC、AP。
- **患者级MAE**：先汇总每位患者所有ROI的预测与GT计数，再计算绝对差并平均（TIL评分的临床决策单位是患者）。
- **亚型级MAE**：按ROI聚合（大多数患者每亚型仅贡献少量ROI）。
- **消融指标**：选择性 = FP↓%/TP↓%（衡量假阳性去除的精准度）。

### 3.4 实现细节
- CellViT++ + 冻结SAM-H编码器；MLP架构一致，唯一变量是监督信号。
- Adam优化器；Stage 1：20 epochs、lr=1e-4；Stage 2：5 epochs、lr=1e-5。
- UOT/蒸馏超参数在训练集上根据MLLM密度差选择；训练中**不使用细胞级GT**。

## 6. 论文的主要结论与发现

- **区域级MLLM弱监督可带来实质性提升**：Context-soft在所有患者级指标上超越Lizard，MAE从83.8降至68.5——说明即使不完美的MLLM先验也能有效引导抑制系统性过计数。
- **UOT蒸馏带来精准的误差削减**：Loki-OT相较Context-soft，MAE再降32.8%（68.5→46.0），同时精度提升；以牺牲部分召回为代价换取更精准的细胞分配。
- **弱监督可超越全监督**：Loki-OT在患者级MAE（46.0 vs 58.3，p=0.031）和F1（0.543 vs 0.474，p<0.001）上均优于in-domain全监督PanopTILs。
- **误差集中之处收益最大**：在模拟最密集的上皮组织（T1浸润性肿瘤、T3原位癌、T4健康腺体）中，Loki-OT的MAE改进最显著。
- **两阶段各有分工**：Stage 1清除“易”假阳性，Stage 2（UOT）处理依赖上下文的“难”模拟——选择性从7.84×提升到3.32×（更低更好），TP损失从37.1%降至16.8%。
- **Loki-OT优于直接用UOT教师**：选择性蒸馏阈值（Δ≥10%）使学生学会**何时信任教师**，比直接蒸馏UOT教师具有更低的TP损失和更高的选择性。

## 7. 优点

- **问题切入点贴近临床**：以TIL评分中真实的“细胞模拟”难题为靶点，而非一般性分类任务，临床动机清晰。
- **方法论创新强**：将UOT从领域自适应/单细胞响应比较扩展到“区域先验→细胞分配”的知识传导，形式上优雅、解释性强。
- **实现经济高效**：推理阶段仅需轻量MLP（无MLLM、无OT），工程上易部署。
- **两阶段课程设计合理**：先学区域规律再学细胞重分配，规避了直接蒸馏的不稳定性；触发阈值设计（Δ≥10%）基于MLLM先验误差（≈11.7%）有据可依。
- **评估严谨**：使用bootstrap置信区间、显著性检验、Holm校正、按组织亚型细分分析，统计方法规范。
- **代码开源**：可复现性强。

## 8. 不足与局限

- **泛化范围有限**：仅在乳腺癌（TCGA-BRCA）单一队列验证，未覆盖其他癌种或细胞类型；训练/测试分布也存在明显组成偏移（T1为主→T6为主）。
- **MLLM先验粗粒度**：MAE=11.7%且偏差+6.6%，是“方向正确但数值不准”的信号；若MLLM先验系统性偏差更大，UOT纠正可能适得其反（OT-Teacher的严重TP损失即为警示）。
- **非对称纠错策略**：机制优先压制假阳性（提高精度），以牺牲召回为代价——在淋巴细胞富集区域（如T6炎症间质）可能漏掉真实阳性。
- **逻辑代价适用范围受限**：仅对上皮丰富组织（T1/T3/T4）生效；非上皮区域中形态模拟的判别仍需更强机制。
- **消融实验在训练集上进行**：OT/UOT教师仅存在于训练管线中，无法在独立测试集评估，限制了对各组件泛化性能的直接判断。
