## 摘要
全切片多实例学习（MIL）仅观察其选择器所接受的补丁。部署过程中，即使补丁数量不变，计算限制、组织掩膜或区域工作流也可能改变这一选择器。我们提出了BagShift，一种配对协议，在同一病例上更换选择器，同时保持其特征和预测器固定，从而将选择器响应与病例混合分离。在同等128补丁预算下，跨组织采样或围绕单一坐标集中采样会暴露显著不同的证据：在PANDA上，两种视图分别使二次加权卡帕降低1.57和17.96个点（QWK按×100尺度报告）。在CAMELYON16上，模型开发中 withheld 的病变注释显示，局部视图仅在10.0%的微转移观察中保留肿瘤，且匹配暴露并不能一致地恢复损失。同样的固定计数压力在外部肺亚型分类上产生的响应要小得多，尽管相对覆盖率的差异使跨任务严重性具有描述性。当可获得重复的局部观察时，在单次非线性MIL传递前对其补丁取并集，比平均区域预测在PANDA QWK上提高7.87个点。补丁数量指定的是计算量，而非观察到的证据；部署评估应同时报告选择器保留了什么以及重复观察如何聚合。

## Abstract
Whole-slide multiple-instance learning (MIL) observes only the patches admitted by its selector. Deployment can alter this selector through compute limits, tissue masking, or regional workflows, even when the patch count is unchanged. We introduce BagShift, a paired protocol that changes the selector for the same case while holding its features and predictor fixed, thereby isolating selector response from case mix. With equal 128-patch budgets, sampling across the tissue or concentrating around one coordinate exposes markedly different evidence: on PANDA, the two views reduce quadratic weighted kappa by 1.57 and 17.96 points, respectively (QWK reported on the $\times100$ scale). On CAMELYON16, lesion annotations withheld from model development show that localized views retain tumor in only 10.0\% of micrometastatic observations, and matched exposure does not consistently recover the loss. The same fixed-count stressor produces a much smaller response on external lung subtyping, although differences in relative coverage make cross-task severity descriptive. When repeated localized observations are available, unioning their patches before one nonlinear MIL pass improves PANDA QWK by 7.87 points over averaging regional predictions. Patch count specifies computation, not observed evidence; deployment evaluations should report both what a selector preserves and how repeated observations are aggregated.

# 论文总结

## 1. 核心问题与整体含义

**研究动机与背景：**
- 全切片多实例学习（MIL）在计算病理学中广泛用于弱监督诊断，模型仅观察由"选择器"（selector）筛选出的补丁子集。
- 实际部署时，选择器可能因计算预算、组织掩膜或区域工作流而改变，即使补丁数量不变，模型所见证据也会显著不同——128个分散补丁可覆盖整个组织，而128个相邻补丁仅集中在单一区域，两者计算成本相同但诊断证据可能完全不同。
- 现有评估存在盲区：**cohort shift** 基准（如 WILDS）在固定袋构建下更换病例，无法隔离选择器变化带来的影响；选择性检查方法（如 EAGLE、TRUECAM）关注如何选择更好的选择器，而非衡量选择器变化对已训练模型的影响。
- **核心问题**：在相同病例、相同特征、相同预测器的条件下，仅改变选择器（patch 选择策略）会对模型性能产生多大影响？现有评估将"计算量（patch 数）"等同于"观察到的证据"，而本文论证这是错误的。

## 2. 方法论

**核心思想：**
- 引入 **BagShift**，一种配对（paired）干预协议：在同一病例、同一标签、冻结特征和预测器的情况下，仅更改观察到的 patch 集合，从而隔离选择器响应与病例混合（case mix）。

**关键技术细节：**
- **形式化定义**：设参考提取通道 A₀ 产生袋 Bᵢ = {(xᵢⱼ, cᵢⱼ)}，观察政策 p 通过选择分布 qₚ(·|Bᵢ) 暴露非空子袋 Bᵖ,ωᵢ。政策是选择分布，选择器绘制是一次实现，得到的子袋是观察视图。
- **政策类型**：
  - 空间政策（spatial）：以随机锚点为中心，保留最近的 128 个 patch。
  - 分散预算政策（dispersed budget）：从所有基数为 b 的子集中均匀采样。
  - 随机保留（random retention）：随机保留 50%–100% 的 patch。
  - 条带压力（stripe stressor）：沿随机轴保留最近的 128 个 patch。
- **配对评估指标**：∆M(p) = M(p₀) − M(p)，要求同时报告参考和受限指标水平，防止仅通过削弱参考预测来降低退化。
- **匹配策略训练控制**：
  - 平均匹配暴露（average）：L_avg = (1/N)Σ(ℓ⁰ᵢ + α·(1/|P'|)Σₚℓᵖᵢ)
  - 最差策略风险（worst）：L_worst = (1/N)Σ(ℓ⁰ᵢ + α·maxₚℓᵖᵢ)，maximum 在病例内跨政策取，而非跨批次或提供者。
  - 共享预测器贯穿所有视图，仅索引集 Iₚ 改变。

## 6. 主要结论与发现

1. **等 patch 数可保留不等证据**：PANDA 上，128 个分散 patch 仅使 QWK 下降 1.57 点，128 个局部 patch 下降 17.96 点；匹配训练无法消除几何差距（15.30 点）。
2. **局部选择错过局灶性证据**：CAMELYON16 上，局部窗口在仅 10.0% 的微转移观察中保留肿瘤（随机预算为 52.6%）；匹配暴露无法恢复此损失。
3. **跨任务响应差异大**：同样的压力在 TCGA-to-CPTAC 外部肺亚型上仅损失 0.56 AUROC 点，表明响应并非普遍严重。
4. **聚合顺序关键**：重复局部观察时，**先合并 patch 再做一次非线性 MIL** 比平均区域预测在 PANDA QWK 上高 7.87 点（K=5）；K=20 时联合覆盖 99.3% 时几乎重建参考预测，而平均预测仍低于参考 8.68 点。
5. **核心宣言**：Patch 数指定的是计算量而非观察证据；部署评估应报告选择器保留了什么证据以及重复观察如何聚合。

## 7. 优点

- **方法设计创新**：BagShift 通过病例内配对干预将选择器效应从病例混合中分离出来，将 patch 构建转化为可审计的部署组件。
- **机制验证深入**：CAMELYON16 利用 withheld 病灶注释建立肿瘤保留率与概率响应之间的直接联系（Spearman ρ = 0.588），不仅报告性能下降还解释其机制。
- **控制矩阵严谨**：区分了泛化正则化、政策暴露、权重、鲁棒聚合等四种改善来源，避免了"仅训练帮助"的空泛结论。
- **诚实处理探索性分析**：对 α 扫描的事后特征、组织成分清理的政策事后选择、早期 CVaR/EMA 诊断等均明确标注为探索性而非确证性。
- **实践指导明确**：提供了具体的部署审计建议和可复现的代码/数据发布边界。

## 8. 不足与局限

- **跨任务因果归因受限**：PANDA/CPTAC 的 128-patch 预算仅为参考池的 25%，而 CAMELYON16 约为中位袋的 2.5%，相对覆盖率差异使跨任务严重性仅为描述性，不能归因于证据局部性本身。
- **CAMELYON16 病灶分析规模小**：仅 27 张微转移切片，且无 XML 的一例宏转移被排除在机制分析外；分类指标中宏转移保留率（42.9%）也远低于随机控制。
- **匹配暴露的监督冲突**：局部正视图常不含标注肿瘤却继承阳性标签，造成监督冲突；作者未验证其他实例级策略是否可解决此问题。
- **PANDA 上游依赖**：使用发布的 UNI2-h 特征档案，其上游组织选择规则未说明，响应曲线对候选池条件依赖。
- **架构探测不完整**：仅测试 α=0.5 的架构对比，未运行所有权重扫描；最差政策优势在 Attention 大权重下减弱，跨架构不等同。
- **双医院测试范围有限**：不是 WSI ROI 验证，而是多图像选择测试，不能直接推广到坐标级选择；H1/H2 图像访问受机构治理约束。
- **探索性偏差风险**：组织成分清理政策为事后选择、α 扫描为测试后检查，作者虽明确指出但无法完全消除偏差风险。
