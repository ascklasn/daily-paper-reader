## 摘要
全切片图像（WSI）报告生成需要识别空间分布的病理特征并将其组织成连贯的诊断叙述。尽管直接的视觉到文本模型可以生成流畅的报告，但它们掩盖了视觉识别、结构化推理和语言生成的贡献及失败模式。我们提出了一个分解框架，其中冻结的Virchow2切片嵌入通过多实例学习（MIL）分类头进行聚合，以回答器官特定的诊断问题。器官条件图约束这些答案组装成结构化推理链，语言模型将其实现为病理报告。在包含2,028张切片的REG2026留出集上，所提出的工作流实现了链Jaccard得分为0.702。在没有基于图的链构建的情况下，性能降至0.420；当器官特定图被单一器官无关图替换时，性能降至0.398；当语言模型从MIL预测中自由构建链时，性能降至0.371。使用相同的报告生成器，图结构链将报告得分从0.330提高到0.495。在涵盖七个REG器官的350张外部TCGA WSI上，无需微调，预期器官图在64.0%的情况下被选中，并在86.6%的情况下排名前三。提供正确的器官图将粗略TCGA主要诊断标签的一致性从61.8%提高到92.6%，表明器官路由是领域转移下的主要瓶颈。总体而言，器官条件、图约束的链组装改善了结构化推理和报告生成，同时实现了阶段特定的错误定位。

## Abstract
Whole-slide image (WSI) report generation requires recognizing spatially distributed pathological features and organizing them into a coherent diagnostic narrative. Although direct vision-to-text models can yield fluent reports, they obscure the contributions and failure modes of visual recognition, structured reasoning, and language generation. We propose a decomposed framework in which frozen Virchow2 tile embeddings are aggregated by multiple-instance learning (MIL) classification heads that answer organ-specific diagnostic questions. An organ-conditioned graph constrains the assembly of these answers into a structured reasoning chain, which a language model realizes as a pathology report. On the REG2026 held-out set of 2,028 slides, the proposed workflow achieved a chain-Jaccard score of 0.702. Performance fell to 0.420 without graph-based chain construction, 0.398 when the organ-specific graphs were replaced by a single organ-agnostic graph, and 0.371 when the language model constructed the chain freely from MIL predictions. Using the same report generator, graph-structured chains improved the report score from 0.330 to 0.495. On 350 external TCGA WSIs spanning the seven REG organs without fine-tuning, the expected organ graph was selected in 64.0% of cases and ranked among the top three in 86.6%. Providing the correct organ graph increased agreement with coarse TCGA primary-diagnosis labels from 61.8% to 92.6%, identifying organ routing as a main bottleneck under domain shift. Overall, organ-conditioned, graph-constrained chain assembly improves structured reasoning and report generation while enabling stage-specific error localization.

### 1. 论文的核心问题与整体含义（研究动机与背景）

全切片图像（Whole Slide Image, WSI）病理报告生成是计算病理学中的重要任务，要求模型在分析千兆像素级组织图像的基础上，生成结构化的临床诊断报告。现有方法通常将视觉识别、诊断推理和语言生成耦合在端到端的“视觉—文本”模型中。这类直接生成的方式虽然可以产生流畅的报告，但存在一个根本问题：**当生成的报告出错时，难以判断错误源于视觉证据遗漏、诊断路径选择不当，还是语言表达错误，导致系统缺乏可解释性和阶段级错误定位能力**。

针对这一痛点，论文提出将 WSI 报告生成任务显式分解为三个可独立检验的阶段：
1. **视觉证据预测**（Visual Evidence Prediction）
2. **图约束的器官方诊断推理**（Graph-Constrained Diagnostic Reasoning）
3. **报告实现**（Report Realization）

整体意义在于：通过这种分解设计，不仅能提升报告生成的结构化质量和准确性，还将“黑箱”式的端到端生成转变为可解释、可回溯、可局部化错误来源的模块化工作流。

### 2. 论文提出的方法论

#### 2.1 核心思想

采用“**冻结视觉编码器 + 多实例学习分类头 + 器官条件图引导的推理链组装 + 语言模型报告生成**”的级联框架。将病理报告生成从直接的视觉—语言映射改造为结构化推理链条驱动下的受控生成，使每个中间步骤（器官判定、问题回答、链组装、报告实现）均可独立评估和验证。

#### 2.2 关键技术细节

**（1）切片编码与视觉特征提取**

- 将 WSI 切分为非重叠的 224 × 224 像素的切片（tiles）。
- 仅保留组织切片：至少 50% 像素的 RGB 均值强度低于 220。
- 每个切片包（bag）最多采样 128 个组织切片（训练和推理时使用固定种子的均匀随机采样）。
- 使用**冻结的 Virchow2 病理学基础模型**（ViT-H）作为编码器。
- 每个 tile 的表示 $\mathbf{x}_i$ 由类标记（class token）向量与其余 patch token 的均值向量拼接而成，维度为 2560：

$$\mathbf{x}_i = \left[ \mathbf{O}_{i,0}; \frac{1}{L-5} \sum_{\ell=5}^{L-1} \mathbf{O}_{i,\ell} \right] \in \mathbb{R}^{2560}$$

- 一张切片表示为变长嵌入包：

$$\mathbf{X}_s = \{\mathbf{x}_{s,i}\}_{i=1}^{N_s}, \quad N_s \le 128$$

**（2）多实例学习（MIL）分类头**

- 采用**门控注意力 MIL**（Gated Attention MIL, Ilse et al. 2018）获得注意力加权的切片级表示。
- 两类分类头：
  - **器官分类头**：7 类多分类，用于路由选择器官特异性工作流。
  - **问题特异性分类头**：针对器官图中的每个标准诊断问题，分别训练二分类或多分类头，用于回答具体问题。
- 每个问题头仅在与该问题对应的训练样本上训练（训练样本的参考链中包含该问题）。

**（3）器官条件图构建与链组装**

- 从 REG2026 数据集的链式推理（CoT）标注中抽取每个器官的**有向图**：

$$\mathcal{G}_o = (\mathcal{V}_o, \mathcal{E}_o, \mathcal{A}_o, \mathcal{T}_o)$$

其中 $\mathcal{V}_o$ 为标准诊断问题节点，$\mathcal{E}_o$ 为答案条件转移边，$\mathcal{A}_o$ 为答案词表，$\mathcal{T}_o$ 为转移函数。

- **推理流程**：
  1. 器官路由器选择图：$\hat{o}_s = \arg\max_o p_{\theta_{org}}(o \mid \mathbf{X}_s)$
  2. 从图起始节点遍历，当前问题 $q_t$ 由对应的 MIL 头回答：$\hat{a}_t = \arg\max_{a \in \mathcal{A}_{\hat{o}_s, q_t}} p_{\theta_{\hat{o}_s, q_t}}(a \mid \mathbf{X}_s)$
  3. 按图转移函数确定下一问题：$q_{t+1} = \mathcal{T}_{\hat{o}_s}(q_t, \hat{a}_t)$
  4. 反复迭代至终止，输出有序的问答链：$\hat{C}_s = ((q_t, \hat{a}_t, q_{t+1}))_{t=1}^{T_s}$

- 图结构为确定性结构，从训练工作流中提取；器官路由器与所有问题 MIL 头均以交叉熵损失训练。

**（4）报告生成**

- 使用 **Qwen2.5-1.5B-Instruct** 语言模型，通过 LoRA 适配器微调。
- 条件输入为推理链（而非图像特征），以自回归语言模型目标训练。
- 最终报告是在图约束链基础上实现的，语言模型仅承担“将结构化链转化为自然语言报告”的角色。

### 6. 论文的主要结论与发现

1. **图约束分解式工作流全面优于各消融变体**：
   - 完整模型在留出集上的链-Jaccard 达 **0.702**，比无图组装（0.420）高 0.282，比单一器官无关图（0.398）高 0.304，比自由形式（0.371）高 0.331。
   - 完整模型在全部 7 个器官上均为最佳配置。

2. **图结构的贡献超出“格式化”层面**：
   - 与 Canonical 模板（0.572）和 Shuffled 对照（0.320）相比，完整模型的提升表明图结构本身的约束与转移逻辑对推理质量有实质贡献。

3. **结构化推理链能有效改善报告生成**：
   - 相同报告生成器条件下，图约束链（0.495）比扁平事实输入（0.330）的报告分提升 0.165，且对所有器官均为正增益（+0.020 ~ +0.284）。
   - 参考链（GT-chain）将报告分进一步推至 0.658，说明链质量仍有提升空间。

4. **错误集中分布于细粒度属性**：
   - 分级/量化问题准确率最低（0.686），与诊断/亚型问题合计贡献了 75% 的节点级错误。
   - 存在/范围（0.942）和工作流/模式（0.963）问题则高度可靠。

5. **域迁移下器官路由是主要瓶颈**：
   - 外部 TCGA 数据上，Top-1 器官路由准确率降至 0.640（0.968–1.000 → 各器官 0.220–0.940 不等）。
   - 提供正确器官图后，弱诊断一致性从 61.8% 跃升至 92.6%，证明外部失败主要源于工作流选择（器官路由），而非器官内诊断推理。

6. **官方指标表现**：
   - 留出集 Workflow-A 达 0.725（BPV 0.592、Edge-F1 0.914、MESS 0.894、Report 0.495）。
   - TP1 提交成绩为 0.683，各子指标未出现单项崩溃（Edge-F1 保留 84%、MESS 79%、Report 71%；BPV 因精确匹配敏感性仅保留 38%）。

### 7. 优点

#### 方法设计亮点

- **显式分解、逐阶段可解释**：将 WSI 报告生成拆分为视觉证据、结构化推理和语言生成三个环节，错误可以在具体阶段被定位，而非笼统归结为“模型出错”。
- **利用器官条件图约束推理**：将临床知识（器官特异性诊断路径）编码为确定性图结构，充分利用 REG2026 提供的 CoT 标注，使推理过程既受领域知识约束又保持可预测性。
- **模块化 + 冻结编码器**：使用冻结的 Virchow2 基础模型，只训练轻量 MIL 分类头，参数效率高、训练成本相对可控。
- **语言模型角色限定**：Qwen 仅用于“将结构化链转化为报告”，能有效避免幻觉式自由生成，降低事实偏离风险。

#### 实验设计亮点

- **消融体系完整**：逐一移除视觉证据、图结构、器官条件、自由构建等要素，使每个组件的增益可量化。
- **多维度评估**：链级相似度、逐问题准确率、词表有效性、转移一致性、官方流程评分、报告子指标等多角度交叉验证。
- **外部域迁移压力测试**：TCGA 实验检验泛化能力，并利用预言机器官图揭示了瓶颈所在，具有很强的诊断价值。
- **误差的类别级归因**：按问题类型细分错误来源，为后续改进指明方向。

### 8. 不足与局限

1. **实验覆盖方面的局限**：
   - 外部 TCGA 评估缺乏参考报告和 REG 风格 CoT 标注，仅能进行弱诊断一致性检验，无法直接评估生成报告的临床事实准确性。
   - 报告评估全部依赖自动指标（BLEU、ROUGE-L、Jaccard、嵌入相似度），无病理学家的临床审阅或人工评分。
   - TP1 与留出集使用不同模型/数据/采样方式，跨设置比较的结论需谨慎解读。

2. **方法本身的局限**：
   - 器官图从 REG2026 标注中提取，可能无法覆盖未见过的工作流或新器官，限制了泛化能力。
   - 冻结 Virchow2 编码器 + 128 tile 上限可能丢失细粒度分级线索或稀疏诊断区域的关键视觉证据。
   - MIL 分类头对“分级/量化”类问题的准确率显著偏低（0.686），这是报告质量进一步提升的核心障碍。

3. **偏差风险与应用限制**：
   - 训练数据来自特定挑战赛的标注体系，可能存在标注者偏差；测试集剔除了 213 张同病例切片，避免了数据泄漏，但也减少了测试规模。
   - 器官路由在外部数据（尤其膀胱、宫颈、胃）上明显下降（Top-1 分别仅 0.220、0.340、0.460），说明域间组织形态差异对路由模型影响较大，实际部署前需要领域适配。
