## 摘要
长周期智能体正开始自动化生成代码、报告和研究产物的完整工作流程。医学影像工作流是多阶段且数据敏感的，而专家轨迹仍然稀缺且难以共享。结构化基准可以通过阶段级评估标准来定位失败，但标准的后训练在下一次训练轮次之前会丢弃这些诊断信息。我们提出了Benchmark-as-Teacher（BaT），一个用于智能体后训练的递归自我改进系统。BaT包含两个关联组件：异步阶段库数据管道和BiCuRL（双课程强化学习），后者是其自我改进的后训练方法。阶段库在策略更新循环之外合成内容隔离的训练状态。BiCuRL使用固定的保留评估来选择下一阶段课程，用任务评估标准验证生成结果，通过GRPO更新策略，并将候选检查点返回评估。在AutoMedBench-Lite上，BaT-4B和BaT-9B的整体得分比其Qwen Instruct基线提高了一倍以上。BaT-9B智能体达到79.6的整体得分，超过了使用Claude Code的Claude Opus 4.6的77.5分。

## Abstract
Long-horizon agents are beginning to automate complete workflows that produce code, reports, and research artifacts. Medical imaging workflows are multi-stage and data-sensitive, while expert trajectories remain scarce and difficult to share. Structured benchmarks can localize failures through stage-level rubrics, but standard post-training discards these diagnostics before the next training round. We present Benchmark-as-Teacher (BaT), a recursive self-improvement system for agent post-training. BaT contains two linked components: the asynchronous Stage Bank data pipeline and BiCuRL (Bilevel Curriculum Reinforcement Learning), its self-improving post-training method. Stage Bank synthesizes content-isolated training states outside the policy-update loop. BiCuRL uses a fixed held-out evaluation to select the next stage curriculum, verifies rollouts with task rubrics, updates the policy with GRPO, and returns the candidate checkpoint to evaluation. On AutoMedBench-Lite, BaT-4B and BaT-9B more than double the Overall scores of their Qwen Instruct baselines. BaT-9B Agent reaches 79.6 Overall, exceeding Claude Opus 4.6 with Claude Code at 77.5.

## 2. 论文提出的方法论

### 2.1 核心思想

BaT 由两个耦合组件构成：

1. **Stage Bank（阶段库）数据管道**：在策略更新循环之外，异步合成内容隔离的、可执行的训练状态（sandboxes）。
2. **BiCuRL（Bilevel Curriculum Reinforcement Learning，双层课程强化学习）**：自我改进的后训练方法，将评估、训练、再评估连接成闭环。

### 2.2 阶段库（Stage Bank）关键技术

- 将带阶段的基准形式化为：**ℬ = (𝒮, 𝒞, 𝒱)**，其中 𝒮 为有序公共阶段，𝒞 为评估标准（rubric）和证据契约，𝒱 为固定的留出评估集。
- 数据合成：
  - 使用教师模型生成虚构的医学影像任务，并在公共工作流描述指导下完成多轮轨迹；
  - **SFT 行**：将多轮教师轨迹切片为“上下文 + 单条教师回复”，用于冷启动监督微调；
  - **RL 行**：构建可执行的沙箱状态，支持完整多轮 rollout。
- 训练数据池分为三类：
  - **S-target**：当前被选中的薄弱阶段；
  - **S-mix**：其余阶段的混合，防止遗忘；
  - **E2E surrogate**：缩小版完整工作流，保持跨阶段协调能力。
- **泄漏防护（leakage preflight）**：在数据进入训练前，拒绝任何包含留出任务 ID、路径、报告、轨迹、答案及评估衍生元数据的行。
- 每个 Stage Bank 行表示为：**zᵢ = (pᵢ, sᵢ, cᵢ, 𝒢ᵢ, κᵢ, mᵢ)**，含沙箱状态、阶段标识、rubric 项、证据要求、阶段技能和溯源信息。

### 2.3 BiCuRL 双层优化

BiCuRL 的目标函数为双层优化问题：

```
max over q ∈ 𝒬_SB   ℳ(θ̂(q))
s.t.  θ̂(q) ∈ arg max over θ  𝒥_GRPO(θ; q)
```

- **外层循环（Curriculum Teacher）**：
  - 读取固定留出评估的阶段得分 e_r = (e_{r,s})，选择下一轮薄弱阶段 s*；
  - 按固定比例混合三个池：**q_r = ρ_target·q_target + ρ_mix·q_mix + ρ_E2E·q_E2E**（实际比例为 1/2 : 1/4 : 1/4）；
  - 实现 **checkpoint fallback**：连续 3 轮分数下降或 KL 散度超过阈值 τ=0.1 时，回退到最佳保留检查点。
- **内层循环（Rubric-Verified Agentic RL）**：
  - 从阶段库采样状态，策略生成 K 条 rollout；
  - LLM 评估器依据 rubric 项和工件证据对每条 rollout 做二元判定，并计算证据完整度 η；
  - 奖励：**r_{i,k} = η_{i,k} · (1/|c_i|) · Σ v_{i,k,ℓ}**，再经组归一化得到优势 A_{i,k}；
  - 使用 **GRPO** 更新策略，优势分配给 rollout 中的每个生成 token（见附录 A.2 的多轮监督目标函数）。

## 6. 论文的主要结论与发现

1. **主导结果——BiCuRL 使基线得分翻倍以上**：
   - BaT-4B：Overall 从 6.1 → 22.9；
   - BaT-9B：Overall 从 19.9 → 53.4，且比 GRPO 单独训练高 21.5 分。

2. **收敛行为**：BaT 在训练轮次中持续提升，而 GRPO 早期饱和；原始轮次曲线有波动，检查点保留和回退机制保住了最佳分数。

3. **消融结论**：完整三池混合（S-target + S-mix + E2E）领先所有部分组合，至少高出 21.5 Overall 点；每个“去掉一个池”的组合至少落后 26 点。

4. **本地部署优势**：BaT-9B 在 <40B 本地模型中排名第三（53.4），仅次于 Qwen3.6-27B（65.3）和 Qwen3.5-35B-A3B（57.9）；在 <12B 的“tiny”模型中排名第一。

5. **顶级系统对比**：BaT-9B Agent 在 AutoMedBench-Lite 上达到 79.6 Overall，超过 Claude Opus 4.6 + Claude Code（77.5）；在 ABRA 上落后 GPT-5.5 + Codex 9.3 分，在 MedXpertQA-Text 上落后 Gemini 3.1 Pro 14.8 分。

6. **迁移结果与规模相关**：
   - **BaT-9B**：在 AIME 和 GPQA-Diamond 上仅下降 3.4–5.8 分，在 τ²-Bench（+5.4）、SWE-bench Verified（+2.8）和 Terminal Bench 2.0（+1.4）上提升；
   - **BaT-4B**：在全部 8 个外部基准上均下降（大幅下降，如 BFCL-Parity -52.0，τ²-Bench -50.8）。

7. **总体结论**：结构化基准可以同时充当评估者和后训练教师，Stage Bank + BiCuRL + 固定执行层构成了一个递归自我改进系统。

## 7. 优点

- **方法创新性强**：将输出-only 基准转变为训练基础设施，核心思路新颖——只在评估与训练之间传递“聚合分数”而非“任务内容”，在数据边界上做了严格设计。
- **数据工程严谨**：Stage Bank 的泄漏预检、溯源记录、可执行沙箱、rubric 证据契约等设计完整，保证了训练数据的可控性和可复现性。
- **双层课程设计**：外层做阶段路由和检查点回退，内层做 rubric 验证的 GRPO 更新，二者解耦清晰，且具备向其他分期基准迁移的普适性（见附录 Proposition 1）。
- **评估粒度细**：同时报告 Task（成果）与 Agentic（过程）分数，能够区分改进来自流程还是结果；统计上以轨道为独立单位，避免伪重复。
- **实验覆盖面广**：2 个模型规模、4 种训练方法、7 种消融组合、19 个本地模型、3 个医学基准、8 个外部基准，验证相对充分。
- **工程贡献明确**：代码开源（github.com/AutoMedBench/Benchmark-as-Teacher），训练数据、提示词、泄漏规则将一并发布。

## 8. 不足与局限

- **基准参与训练的问题**：AutoMedBench-Lite 的聚合诊断信号参与了训练课程的选择，尽管任务内容被隔离在训练之外，但该基准并非严格意义上的“未触碰最终测试”。论文承认需要独立的最终测试和语义泄漏审计作为未来工作。
- **外部对比的公平性**：外部基准表格混合了本地复测和已发表的基线数值，缺乏完整的逐运行清单；顶级系统对比绑定了各自的执行环境，只能做系统级结论，无法分离策略本身的效果。
- **小模型的灾难性遗忘**：BaT-4B 在全部 8 个外部基准上均低于基线，表明在较小模型上医学专用训练会造成严重的一般能力损失；论文对此现象缺乏深入分析或缓解方案。
- **计算资源报告不完整**：未报告端到端训练总时长、总 GPU 小时数、rollout 总 token 消耗量，难以评估方法的计算成本。
- **统计显著性缺失**：主要分数差异未做显著性检验；ABRA 和 MedXpertQA-Text 上与顶尖模型的差距未给出误差范围或逐轨道细节。
- **适用范围限制**：当前方法依赖“具有稳定阶段边界、阶段级分数和可自动化 rubric 评分”的基准；对于无此结构的基准，迁移适用性未经验证。
- **ABRA 和 MedXpertQA 的局限**：BaT-9B 在这些基准上仍落后顶尖模型 9–15 分，领域泛化能力有待提升。
