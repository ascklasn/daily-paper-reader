## 摘要
准确且负责任的医学问答（QA）在医疗保健中至关重要，因为复杂病例需要事实性知识和细致推理。现有的医学问答系统通常基于单智能体架构和静态检索，往往缺乏适应性、持久记忆和结构化决策。本研究引入了一种自适应记忆与反思（AMR）智能体系统，这是一个多智能体框架，其中专门的智能体利用专用记忆和基于反思的反馈来检索相关既往病例并改进后续推理。复杂度评估将问题路由到独立、协作或升级工作流中，同时共识与伦理监督模块支持推理整合和输出审查。在MedQA和MedMCQA上的评估表明，与几种基线相比，该系统表现出强劲的性能。消融研究显示，结合智能体特定记忆、反思和外部检索可获得最佳性能。这些发现凸显了结构化记忆和反馈在开发更值得信赖的医学智能体方面的潜力。源代码公开于https://github.com/mm-air/AMR-Agent。

## Abstract
Accurate and responsible medical question answering (QA) is important in healthcare, where complex cases require factual knowledge and nuanced reasoning. Existing medical QA systems, typically based on single-agent architectures and static retrieval, often lack adaptability, persistent memory, and structured decision-making. This work introduces an adaptive memory and reflection (AMR) agentic system, a multi-agent framework in which specialized agents use dedicated memory and reflection-based feedback to retrieve relevant prior cases and improve subsequent reasoning. Complexity assessment routes questions through solo, collaborative, or escalated workflows, while consensus and ethical overseer modules support reasoning consolidation and output review. Evaluation on MedQA and MedMCQA demonstrates strong performance compared with several baselines. Ablation studies show that combining agent-specific memory, reflection, and external retrieval yields the strongest performance. These findings highlight the potential of structured memory and feedback for developing more trustworthy medical agents. The source code is publicly available at https://github.com/mm-air/AMR-Agent.

## 2. 方法论

### 核心思想
提出 **AMR（Adaptive Memory and Reflection）智能体系统**，一个基于 LangGraph 图结构编排的模块化多智能体框架，包含以下核心模块：

### 关键技术细节

**(1) 自适应路由（Adaptive Routing）**
- Moderator 智能体评估问题复杂度，将问题分为低、中、高三个级别：
  - **低复杂度**：由 General Practitioner 单智能体直接处理；
  - **中复杂度**：多个专科智能体独立推理→共享讨论记录→共识促进者汇总；
  - **高复杂度**：迭代式层级细化（初步报告→评审/修改→决策者终选）。
- 路由机制既是一种计算捷径（避免所有问题都使用相同深度的推理），也是一种控制机制（让推理深度与问题难度匹配）。

**(2) 智能体特定记忆（Agent-Specific Memory）**
- 每个智能体维护**独立的记忆存储**，而非共享的单一记忆库。
- 记忆条目包含：问题上下文、答案、事后笔记、角色元数据和时间戳。
- 记忆通过 text-embedding-3-large 嵌入、FAISS 向量库索引，按语义检索**最相关的 top-5 历史案例**。
- 这种设计使不同角色对同一问题可以检索到不同的既往经验（如肝病科与肾病科视角不同）。

**(3) 反思式反馈学习（Reflection-Driven Feedback Learning）**
- 只有当预测答案与正确答案不一致时，才触发反思循环。
- 反思内容（纠正性反馈、推理修正说明）存储为角色专属的记忆条目，用于改进未来的检索与推理，而非更新模型参数。
- 对应的流程见原文 Algorithm 1：遍历问题→系统给出答案→若与真实标签不符→为团队中每个智能体添加反馈条目。

**(4) 答案合成与输出审查分离**
- Summarizer 将专科推理浓缩为连贯解释；
- Final Answer Picker 将解释映射到最终选项；
- **Ethical Overseer** 在输出发布前按预定义安全标准进行审查，标记为 APPROVED 或 FLAGGED，并记录审查依据供审计。
- 作者强调该模块是**初步安全机制**，不能替代正式临床验证或监管安全评估。

**(5) 角色分工**
- 共定义 9 类智能体角色：Moderator、Recruiter、General Practitioner、Collaborative Agents、Initial Report Agent、Review/Refine Agent、Decision Maker、Summarizer、Ethical Overseer、Final Answer Picker（原文表 I 总结）。

## 6. 主要结论与发现

1. **组合最优**：记忆 + 反思 + 外部检索（RAG）的组合达到最佳性能（MedQA 93.2%，MedMCQA 90.0%），说明三个组件具有互补性。
2. **逐项有效**：单独加入反思（Feedback）或单独加入记忆（Memory）都能带来提升（如 MedQA 上 80%→82%→86%），但两者结合的提升幅度更大（90%）。
3. **优于已有方法**：AMR 优于 GPT-4、MDAgents、MedAgents 等基线，且在 MedMCQA 上达到与人类参考水平（90.0%）相当的准确率。
4. **复杂度路由有效**：中等复杂度问题上准确率最高且标准差最小，表明多智能体协作与迭代讨论机制在该区间表现最优。
5. **反思机制可行**：错误预测触发的角色专属反思记忆可帮助系统在未来类似问题上改善推理。

## 7. 优点与亮点

- **创新性架构设计**：首次在医学 QA 中系统性地整合了角色专属记忆、反思反馈、复杂度感知路由和伦理审查四个要素，突破了传统的单智能体+静态检索范式。
- **临床启发的流程设计**：参照真实临床团队协作流程（专科会诊、上级医师终审、伦理审查），提升了系统的可解释性和可控性。
- **路由机制的效率思维**：不是对所有问题都施以相同推理成本，而是按复杂度分级处理，兼顾效率与效果。
- **记忆的细分设计**：角色专属记忆比单一共享记忆更符合临床实际——不同专科医生的知识侧重点不同，需要检索的内容也应不同。
- **伦理审查的显式化**：将安全审查从推理过程中分离出来，使得政策决策可检视、可审计。
- **系统评价思维**：通过消融测试系统性地验证了各组件交互关系，而非仅做端到端对比。

## 8. 不足与局限

**实验覆盖方面的局限：**
- 仅使用 MedQA 和 MedMCQA 两个**多项选择题基准**，不能完全反映真实临床决策的复杂性和工作流要求；
- 反思机制仅在**回顾性基准**上评估，未在真实临床工作流中验证；
- 定性分析仅含一个成功案例与一个失败案例，样本极少。

**方法本身的局限：**
- 系统性能依赖于**检索质量**，检索不对齐会降低推理一致性；
- 随着记忆积累增多，可能出现重复或低相关案例，导致**记忆退化**；
- 反思基于错误触发，但仅依赖基准的 ground-truth 标签，在无标签的真实场景中难以应用；
- 对反思条目的**优先级管理**、去重和遗忘机制尚未解决。

**安全与应用局限：**
- Ethical Overseer 仅依赖 LLM 知识，**未使用专用临床规则或经过临床医生验证**；
- 作者明确表示当前伦理审查是初步机制，**不能替代正式临床验证或监管安全评估**；
- 隐私、监管合规和实际部署约束未被深入讨论。

**公平性与报告质量局限：**
- 未报告多次实验的方差、置信区间或显著性检验，结果稳定性存疑；
- 对比基线时，GPT-4 等基线未配备同等条件的检索或记忆增强，比较条件不完全对等；
- 未报告推理延迟、token 成本和计算开销等工程指标；
- 未提及实验是否设置了随机种子、是否进行了多次重复以减少偶然性。
