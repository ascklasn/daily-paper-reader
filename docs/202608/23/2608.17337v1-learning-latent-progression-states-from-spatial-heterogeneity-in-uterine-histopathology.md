## 摘要
肿瘤进展伴随着结构、形态和微环境组织的改变，然而与进展相关的异质性在组织病理学中通常被压缩为静态的诊断类别。在此，我们提出了SpaTIE，一个子宫特异性的计算病理学框架，它学习形态学感知的表征，并将空间组织病理学异质性组织为与进展相关的肿瘤状态。SpaTIE使用了10,426张子宫苏木精-伊红（H&E）全切片图像进行开发，并在TCGA-UCEC和TCGA-UCS队列中进行了评估。学习到的表征形成了形态流形，支持诊断、分子和生存相关的预测任务，并将注意力集中于信息丰富的肿瘤区域。除监督预测外，SpaTIE无需时间或分子监督，即可从横断面形态中推断出肿瘤状态轴。这些源自形态的状态在空间上具有一致性，并与临床病理变量和生存结局相关，但并非简单复现分期或诊断标签。整合性多组学分析将推断出的状态与DNA甲基化、体细胞拷贝数变异、突变、RNA-seq和RPPA谱相关联，突出了与染色质调节、拷贝数相关结构变异、受体酪氨酸激酶信号传导、细胞粘附、细胞外基质重塑和代谢适应相关的分子程序。进展引导的虚拟扰动进一步优先考虑了与形态衍生状态组织耦合的分子特征。总之，这些发现表明，子宫组织病理学包含可恢复的进展相关肿瘤状态信息，并使SpaTIE成为连接空间形态学与多组学驱动肿瘤状态发现的框架。

## Abstract
Tumor progression is accompanied by changes in architecture, morphology and microenvironmental organization, yet progression-associated heterogeneity is usually compressed into static diagnostic categories in histopathology. Here we present SpaTIE, a uterus-specific computational pathology framework that learns morphology-aware representations and organizes spatial histopathological heterogeneity into progression-associated tumor states. SpaTIE was developed using 10,426 uterine hematoxylin and eosin whole-slide images and evaluated in TCGA-UCEC and TCGA-UCS cohorts. The learned representations formed morphology manifolds, supported diagnostic, molecular and survival-related prediction tasks, and localized attention to informative tumor regions. Beyond supervised prediction, SpaTIE inferred tumor-state axes from cross-sectional morphology without temporal or molecular supervision. These morphology-derived states were spatially coherent and showed associations with clinicopathological variables and survival outcomes, while not simply recapitulating staging or diagnostic labels. Integrative multi-omics analyses linked the inferred states to DNA methylation, somatic copy-number variation, mutation, RNA-seq and RPPA profiles, highlighting molecular programs related to chromatin regulation, copy-number-associated structural variation, receptor tyrosine kinase signaling, cell adhesion, extracellular-matrix remodeling and metabolic adaptation. Progression-guided virtual perturbation further prioritized molecular features coupled to the morphology-derived state organization. Together, these findings suggest that uterine histopathology contains recoverable progression-associated tumor-state information and establish SpaTIE as a framework for connecting spatial morphology with multi-omics-informed tumor-state discovery.

## 2. 方法论

### 2.1 核心思想
- 假设局部病理观察 \(x\) 由潜在进展状态 \(t\) 和噪声 \(\epsilon\) 生成：
  \[
  x = g(t,\epsilon)
  \]
- 组织切片可视为从多个潜在肿瘤状态中采样的空间分布：
  \[
  p(x) = \int_T p(x|t)p(t)\,dt
  \]
- 若自监督学习后的形态表示保留了进展相关的相似性，则相邻状态在嵌入空间中局部接近，可通过扩散/图方法进行轨迹推断。

### 2.2 表示学习
- 以通用病理基础模型 UNI（ViT-L/16，约 3.03 亿参数，DINOv2 预训练）为初始化。
- 通过 **LoRA 参数高效微调** 进行子宫域适配：LoRA 模块插入注意力层的 query 和 value 投影，权重更新为：
  \[
  W = W_0 + BA
  \]
  其中 \(B \in \mathbb{R}^{m \times r}\)、\(A \in \mathbb{R}^{r \times n}\) 为低秩矩阵。
- 使用 DINOv2 自监督目标继续训练 50 个 epoch，包含图像级自蒸馏损失、iBOT 掩码 patch 级重建损失和 KoLeo 均匀性损失。
- 冻结预训练权重，仅优化 LoRA 参数；AdamW 优化器，学习率 \(1\times 10^{-4}\)，权重衰减 0.998。
- 每个 patch 提取最后一层 CLS token 作为 1024 维特征；slide 级表示通过基于注意力的多实例学习（AB-MIL）聚合：
  \[
  Z = \sum_i a_i z_i, \quad a_i = \frac{\exp(w^\top \tanh(V z_i^\top))}{\sum_j \exp(w^\top \tanh(V z_j^\top))}
  \]

### 2.3 潜在进展状态推断
- 对 slide 级特征标准化后做 PCA，保留解释 90% 方差的成分。
- 构建 k=10 的 k 近邻图，使用高斯核计算邻接权重：
  \[
  K_{ij} = \exp\left(-\frac{\|Z_i - Z_j\|^2}{\sigma^2}\right)
  \]
- 应用 Leiden 社区检测和 PAGA 进行图抽象。
- 使用 **扩散伪时间（DPT）** 推断状态轴，选择形态学上低进展状态的样本作为根节点：
  \[
  t_i = \text{DPT}(Z_i)
  \]
- patch 级状态通过将 patch 嵌入投影到同一流形并进行邻域插值得到，再映射回 WSI 坐标生成空间状态热图。

### 2.4 虚拟扰动分析
- 为每类分子特征计算“KO score”，衡量移除该特征关联成分后，特征与状态关联的衰减程度：
  \[
  \text{KO}(g) = |\rho(t,g)| - |\rho(t_{\text{perturbed}}, g)|
  \]
- 该方法定位为计算假设生成工具，而非因果验证手段。

## 6. 主要结果与发现

### 6.1 自监督病理表示能够重建连续进展状态
- 经子宫域自适应后的 UNI 特征在 UMAP 等可视化中呈现出连续渐变的结构，而非离散簇。
- 基于这些特征推断出的潜在进展轴与 FIGO 分期、基因组改变负担（如 FGA）、肿瘤分级、浸润深度及“先前恶性肿瘤史”等临床病理变量显著相关。
- 在 WSI 空间热图中，进展状态并非均匀分布，而是呈现空间连续的“梯度”，同一张切片内可同时出现低进展和高进展区域，支持“肿瘤进展是多状态共存”的假设。

### 6.2 进展状态具有预后意义
- 进展状态与总生存期相关：高进展状态患者的生存风险显著升高。
- 在亚组分析中，FIGO IV 期、高 FGA、无先前恶性肿瘤等高风险或生物学上更具侵袭性的患者中，进展状态的预后分层尤其明显。
- Cox 回归在校正常规临床病理变量后仍显示进展状态的独立预后价值，提示其可能捕获了传统分期和分级之外的信息。

### 6.3 进展主轴与基因组和分子事件对应
- 对 DNA 甲基化、SCNV、突变、RNA-seq、RPPA 蛋白组五种模态的系统关联分析显示，进展状态不是一个纯组织学描述，而是与多种基因组调控事件耦合。
- 典型的进展相关分子事件包括：TP53/PIK3CA 等驱动基因突变负荷升高、部分抑癌基因启动子甲基化变化、拷贝数扩增/缺失富集、以及细胞周期/免疫相关通路表达改变。
- 虚拟扰动（KO）分析进一步指出：移除某些分子特征对应的形态关联成分后，形态-状态关联下降最显著，从而生成“某分子事件可能驱动或伴随特定形态状态”的可验证假设。

### 6.4 对下游任务的提升
- 使用 SpaTIE 的状态感知表示后，多项下游分类任务（分子亚型、FIGO 分期、组织学分级、关键基因突变、生存状态预测）在 F1 / Acc / AUC 上普遍优于未做域自适应的通用病理基础模型和非病理预训练 baseline。
- 对 UCS 与 UCEC 的形态区分、原发/转移来源判断等任务也表现更优，说明状态推断带来的表示不仅有助于“发现新状态”，也能提升常规监督任务的泛化能力。

## 7. 局限性与潜在缺陷

- **“横断面重建纵向轨迹”的假设验证有限**：SpaTIE 的核心假设——同一切片中不同空间区域对应不同进展状态——目前主要依赖间接关联（分子、预后、临床病理变量）支持，缺少对同一患者多次活检/纵向随访标本的直接验证。
- **根节点选择与轨迹方向存在主观性**：扩散伪时间需要人为指定低进展状态的根样本；若根节点选择偏移，可能影响进展轴的具体方向和生物学解释。
- **分子多组学数据来自整块组织而非局部区域**：TCGA 的突变、甲基化、表达等数据通常来自整块切除标本，而形态状态是局部 patch 的；这种“全组织分子值 vs 局部形态状态”的配对存在空间不匹配，可能高估或扭曲关联强度。
- **保留 90% 方差的 PCA 截断、k=10 的 kNN 图、扩散核带宽等超参数**是否对结果稳健，论文未做系统敏感性分析。
- **虚拟扰动分析的可解释性仍有局限**：它只能度量“特征对形态关联的贡献”，不能证明分子事件与形态状态的因果方向，也无法排除第三变量（如肿瘤微环境）的混淆作用。
- **算力和训练资源披露不足**：未给出 GPU 数量、总训练时长、单卡显存开销和总能耗，可复现性和成本评估不便。

## 9. 创新性与主要贡献

- **概念层面**：将单细胞轨迹推断的思想引入组织病理学，提出“一张切片中多个肿瘤状态共存并可重建连续进展轴”，是对传统离散病理分型的补充。
- **方法层面**：结合通用病理基础模型、LoRA 域自适应、自监督表示学习、扩散伪时间与空间状态图，构建了一套从 WSI 到连续状态轴的完整计算管线。
- **应用层面**：通过多组学、生存数据、虚拟扰动形成“形态-分子-预后”的三角验证，展示了计算病理学从“识别类别”走向“发现过程”的新范式。

## 10. 结论

SpaTIE 通过自监督病理表示学习和基于图的潜在进展推断，提供了从常规 H&E 切片中恢复肿瘤连续进展状态的新途径。该状态轴与临床病理分级、基因组改变、分子通路及患者生存显著相关，且能提升多种下游预测任务性能。尽管存在根节点选择和空间-分子配对等限制，该工作为“组织学作为分子过程读出器”提供了有力证据，是计算病理与肿瘤生物学交叉方向上一个具有启发性的框架性贡献。
